# Settings Page: Custom Commit Prefixes & Terminal Commands

## Data Structure

Settings file: `{userData}/settings.json`

```json
{
  "commitPrefixes": {
    "global": ["feat", "fix", "docs", "style", "refactor", "perf", "test", "build", "ci", "chore", "revert"],
    "projects": {}
  },
  "terminalCommands": {
    "global": ["git status", "git add .", "git push", "git pull", "git fetch", "git log --oneline -20"],
    "projects": {}
  }
}
```

- `global`: applies to all projects
- `projects`: `{ "/path/to/repo": ["custom1", "custom2"] }`, per-project overrides
- Merge logic: project overrides exist → use project list; otherwise → use global list

## Files to Create

### 1. `electron/services/settings.ts` — Settings persistence service
- Same pattern as `repo-manager.ts`: read/write JSON in `app.getPath('userData')`
- Functions: `getSettings()`, `saveSettings()`, `getCommitPrefixes(repoPath)`, `getTerminalCommands(repoPath)`
- `getCommitPrefixes` / `getTerminalCommands` implement the merge logic (project > global)

### 2. `electron/ipc/settings-handlers.ts` — IPC handlers
- `settings:get` → returns full settings
- `settings:save` → saves full settings
- `settings:get-commit-prefixes(repoPath)` → returns merged prefixes for a repo
- `settings:get-terminal-commands(repoPath)` → returns merged commands for a repo

### 3. `src/components/settings/SettingsModal.vue` — Settings UI modal
- Uses `NModal` from naive-ui
- Two sections: "提交前缀" and "终端命令"
- Each section has:
  - A toggle/radio: "全局" / "当前项目"
  - A tag list showing current items (with delete button on each)
  - An input + add button to add new items
  - A "恢复默认" button to reset to defaults
- Reads current repo path from `useRepositoryStore().currentRepo`
